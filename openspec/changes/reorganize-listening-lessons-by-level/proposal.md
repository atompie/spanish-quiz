## Why

Listening/Speaking lesson data is organized under directories numbered by creation order (`lesson_1`, `lesson_5`, ... `lesson_22`), which carries no information about a lesson's CEFR level. One lesson has already been migrated to a level-based directory (`lesson_B1.1`), but the UI shows the raw directory name `"lesson_B1.1"` instead of a friendly `"Lesson B1.1"` label, because the label-formatting logic only recognizes purely numeric lesson ids. The remaining 19 lessons still use the old numbering and need migrating to the same level-based scheme.

## What Changes

- Fix the lesson label formatter so it recognizes CEFR-style ids (level letter A/B/C + sublevel digit 1/2, optional `.N` suffix) and renders them as `"Lesson <id>"` (e.g. `"Lesson B1.1"`), not just legacy purely-numeric ids.
- Fix lesson sorting so CEFR-style ids with multi-digit sub-numbers sort naturally (e.g. `A1.2` before `A1.10`), not lexicographically.
- **BREAKING** (local data only): rename the 19 remaining lesson directories under `public/speak/` from `lesson_<N>` to `lesson_A1.<M>`, preserving current relative order:
  - `lesson_1`->`lesson_A1.1`, `lesson_5`->`lesson_A1.2`, `lesson_6`->`lesson_A1.3`, `lesson_7`->`lesson_A1.4`, `lesson_8`->`lesson_A1.5`, `lesson_9`->`lesson_A1.6`, `lesson_10`->`lesson_A1.7`, `lesson_11`->`lesson_A1.8`, `lesson_12`->`lesson_A1.9`, `lesson_13`->`lesson_A1.10`, `lesson_14`->`lesson_A1.11`, `lesson_15`->`lesson_A1.12`, `lesson_16`->`lesson_A1.13`, `lesson_17`->`lesson_A1.14`, `lesson_18`->`lesson_A1.15`, `lesson_19`->`lesson_A1.16`, `lesson_20`->`lesson_A1.17`, `lesson_21`->`lesson_A1.18`, `lesson_22`->`lesson_A1.19`.
- Update the corresponding top-level keys in `public/speak/metadata.json` to match the new directory names (same mapping as above).
- Regenerate `public/speak/manifest.json` from the renamed directories (it is auto-generated by `scripts/generate-speak-manifest.ts`, so no manual edits are needed there).
- Local `localStorage` "completed lesson" markers keyed by the old ids will no longer match after the rename; this is accepted as a reset of that per-browser state, not a data-loss concern (per-user, non-critical, easily re-marked).

## Capabilities

### New Capabilities
- `listening-lessons`: Listening/Speaking lesson organization and display — lesson ids are CEFR-level-based directory names, and the UI derives a friendly "Lesson <id>" label and correct level-aware ordering from them.

### Modified Capabilities
(none — no existing spec covers this area yet)

## Impact

- `src/components/listening/LessonPicker.tsx` (`lessonLabel()`): broaden id-matching regex.
- `src/lib/listeningSession.ts` (`getAvailableLessons()`): natural sort for level+sub-number.
- `public/speak/lesson_*` directories: 19 renames (directories + contained mp3 files).
- `public/speak/metadata.json`: 19 top-level key renames.
- `public/speak/manifest.json`: regenerated (no manual edit).
- No change to `src/types/speak.ts` or session-building logic — lesson id remains an opaque string key everywhere except the two spots above.
